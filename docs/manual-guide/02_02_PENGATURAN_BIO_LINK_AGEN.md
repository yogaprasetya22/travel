## 📋 Deskripsi Fitur
Pusat kustomisasi website mini Bio Link (Linktree Islami) untuk Mitra Agen agar dapat mempromosikan paket dan menjaring leads secara digital.

## 🛠️ Langkah-Langkah Penggunaan

1. Buka menu Profil Akun > Pengaturan Bio Link Agen.
2. Lengkapi Nama Konsultan, Kota Domisili, dan Kalimat Bio/Komitmen Pelayanan.
3. Atur tombol tindakan: Konsultasi WhatsApp Agen, WhatsApp CS Travel, atau formulir pendaftaran.
4. Tautkan akun media sosial (Instagram, TikTok, YouTube, Facebook).
5. Pantau tampilan pada Live Mobile Preview di sisi kanan.
6. Klik "Simpan Perubahan" dan salin link landing page personal Anda (contoh: `/agen/AG-504A79`).

## 💡 Tips & Catatan Penting

- 💡 Sebarkan tautan Bio Link Anda di Bio Instagram, status WhatsApp, dan kartu nama digital untuk melacak pendaftar referral secara otomatis.
