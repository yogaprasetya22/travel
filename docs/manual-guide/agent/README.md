# Panduan Mitra Agen

Untuk konsultan dan mitra agen yang menjaring dan mendampingi calon jamaah.

## Alur kerja

1. **Bio link**: lengkapi foto, bio, dan tombol WhatsApp di `/profile`.
2. **Promosi**: bagikan bio link (`/agen/AG-XXX`) dan link referral ke media sosial.
3. **Pendaftaran**: terima leads lewat link referral, atau daftarkan jamaah sendiri.
4. **Pendampingan**: kawal kelengkapan berkas (paspor, KTP, buku nikah, vaksin) di papan Kanban.
5. **Pembayaran**: arahkan jamaah transfer ke rekening resmi travel, lalu unggah bukti bayarnya.
6. **Komisi**: pantau saldo komisi langsung dan komisi override sampai dicairkan kantor.

## Daftar halaman

- [Profil dan Bio Link](01_01_SETUP_BIO_LINK_DAN_PROFIL_AGEN.md): Atur profil akun, kata sandi, nomor WhatsApp, bio, dan tautan media sosial. Anda bisa melihat pratinjau tampilan di ponsel sebelum membagikannya.
- [Halaman Bio Link Publik](02_02_TAMPILAN_LANDING_PAGE_BIO_LINK_PUBLIK.md): Halaman milik Anda yang dibuka calon jamaah dari tautan di Instagram, TikTok, Facebook, atau WhatsApp. Isinya profil Anda, tombol chat WhatsApp, daftar paket, dan tombol daftar.
- [Formulir Pendaftaran Lewat Link Referral](03_03_FORM_PENDAFTARAN_JAMAAH_REFERRAL_PUBLIK.md): Calon jamaah mendaftar sendiri lewat tautan referral Anda: memilih paket, mengisi data diri dan nomor paspor, lalu melihat rekening travel untuk transfer DP. Anda otomatis tercatat sebagai pembina.
- [Dari Formulir Publik ke New Leads](04_03A_ALUR_FORM_PUBLIK_KE_NEW_LEADS.md): Data yang diisi calon jamaah di formulir publik langsung masuk ke kolom New Leads di papan CRM Anda, jadi tidak perlu diketik ulang.
- [Mendaftarkan Jamaah Secara Manual](05_04_INPUT_DAN_PENDAFTARAN_JAMAAH_INTERNAL.md): Gunakan cara ini bila calon jamaah mendaftar langsung atau lewat chat pribadi, tanpa membuka tautan referral.
- [Mengunggah Bukti Transfer](06_04B_UPLOAD_BUKTI_TRANSFER_AGEN.md): Setelah jamaah mentransfer DP atau cicilan, unggah foto bukti transfernya di sini. Kantor akan memeriksa dan menyetujuinya.
- [Memantau Pembayaran dan Memindahkan Tahap](07_04C_MONITORING_STATUS_PEMBAYARAN_AGEN.md): Pantau status pembayaran jamaah di papan Kanban, lalu pindahkan jamaah yang sudah sepakat ke tahap berikutnya.
- [Memantau Jamaah Binaan di Kanban](08_05_MONITORING_CRM_PIPELINE_BINAAN.md): Papan Kanban untuk mengikuti jamaah binaan Anda dari booking, DP, kelengkapan berkas, pelunasan, sampai siap berangkat.
- [Jaringan dan Performa Tim](09_05B_MONITORING_POHON_JARINGAN_TIM_AGEN.md): Lihat sub-agen di bawah Anda, omzet tim, dan perkiraan komisi override.
- [Rekap Komisi dan Saldo](10_06_REKAP_KOMISI_DAN_PENCAIRAN_AGEN.md): Lihat saldo komisi, riwayat komisi per jamaah yang sudah lunas, dan status pencairan dari kantor.
