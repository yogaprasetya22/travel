# Halaman Bio Link Publik

Halaman milik Anda yang dibuka calon jamaah dari tautan di Instagram, TikTok, Facebook, atau WhatsApp. Isinya profil Anda, tombol chat WhatsApp, daftar paket, dan tombol daftar.

## Cara menggunakan

1. Sebarkan URL landing page publik Anda (`http://barokah.travel.com/agen/AG-504A79`) ke prospek jamaah.
2. Calon jamaah membuka halaman melalui smartphone atau browser laptop.
3. Calon jamaah dapat langsung berkonsultasi via WhatsApp atau mengklik tombol "Daftar Sekarang".

## Yang bisa dilakukan

### Melihat dan mencari

- Calon jamaah dapat membaca profil konsultan pembina resmi travel.
- Melihat paket-paket umroh yang sedang dibuka beserta harga dan fasilitasnya.
- Melihat ulasan dan testimoni jamaah terdahulu.

### Fitur lain

- Tombol direct chat WhatsApp ke nomor agen secara instan.
- Tombol "Daftar Sekarang" yang otomatis mengarahkan ke formulir registrasi dengan kode referral agen (`AG-504A79`).

## Catatan

- Halaman ini didesain mobile-first sehingga sangat ringan dan cepat saat diakses jamaah melalui smartphone.
