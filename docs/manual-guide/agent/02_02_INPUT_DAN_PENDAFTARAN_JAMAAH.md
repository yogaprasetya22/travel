# Pendaftaran & Input Data Jamaah Binaan

> **Target Peran**: `Agen Mitra (Level 2/3)` | **Login Akun**: `agent2.t2@travel.com`
> **Tahapan Alur**: `2. Pendaftaran & Akuisisi Calon Jamaah` | **Kategori**: `Penjualan & Pendaftaran` | **Rute**: `/crm/customers`

## 📋 Deskripsi Fitur
Modul bagi agen untuk mendaftarkan calon jamaah binaannya secara langsung ke dalam sistem travel menggunakan kode referral otomatis.

## 🖼️ Tampilan Antarmuka

![Tampilan Pendaftaran & Input Data Jamaah Binaan](screenshots/02_input_dan_pendaftaran_jamaah.png)

## ⚡ Aksi & Fitur Lengkap (CRUD Matrix)

### ➕ Create (Tambah / Input Baru)
- Klik "+ Tambah Jamaah" untuk menginput data calon jamaah binaan (Nama, No WA, Alamat, Pilihan Paket).

### 🔍 Read (Lihat / Pencarian / Filter Data)
- Melihat daftar seluruh jamaah yang terdaftar di bawah referral agen Anda.

### ✏️ Update (Edit / Pembaruan Status)
- Perbarui berkas dokumen jamaah (unggah foto Paspor, KTP, Kartu Keluarga, dan Buku Nikah).

## 🛠️ Langkah-Langkah Penggunaan

1. Buka menu CRM > Data Jamaah.
2. Klik tombol "+ Tambah Jamaah".
3. Isi formulir calon jamaah secara lengkap dan pilih paket keberangkatan yang diminati.
4. Simpan data pendaftaran ➔ Jamaah otomatis tercatat di bawah akun agen Anda.
